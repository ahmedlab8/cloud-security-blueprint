# Monitoring

| Path | Contents |
|---|---|
| `prometheus/prometheus.yml` | Standalone scrape config: annotated pods, Falcosidekick, Gatekeeper, kube-state-metrics, cAdvisor |
| `prometheus/rules/security-alerts.yml` | 10 alerts: Falco critical/bursts, brute force, failed-login ratio, Gatekeeper violations or webhook down, restarts, OOM, CPU/memory near limit |
| `prometheus/prometheusrule.yaml` | The same rules wrapped as a `PrometheusRule` CRD (generated by `build_prometheusrule.py`) |
| `prometheus/rules/security-alerts.test.yml` | `promtool test rules` unit tests |
| `alertmanager/alertmanager.yml` | Routes security and critical alerts to Slack and Teams. Webhook URLs are read from mounted secret files |
| `kube-prometheus-stack-values.yaml` | Helm values: hardened Grafana (no anonymous access, no sign-up, secure cookies), non-root Prometheus |
| `grafana/dashboards/*.json` | Security Alerts, Failed Logins, Container Restarts, CPU & Memory |

```bash
kubectl -n monitoring create secret generic grafana-admin --from-literal=admin-user=admin --from-literal=admin-password="$(openssl rand -base64 24)"
kubectl -n monitoring create secret generic alertmanager-webhooks \
  --from-literal=slack-webhook-url="$SLACK_WEBHOOK_URL" --from-literal=teams-webhook-url="$TEAMS_WEBHOOK_URL"
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm upgrade --install kube-prometheus-stack prometheus-community/kube-prometheus-stack \
  -n monitoring -f monitoring/kube-prometheus-stack-values.yaml
kubectl apply -f monitoring/prometheus/prometheusrule.yaml        # generated from rules/security-alerts.yml
```

Validate locally with `make monitoring`.
