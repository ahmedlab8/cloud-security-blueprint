# Grafana dashboards

| Dashboard | File | Highlights |
|---|---|---|
| Security Alerts | `dashboards/security-alerts.json` | Falco events by rule/priority, Gatekeeper violations and denials, firing security alerts |
| Failed Logins | `dashboards/failed-logins.json` | Failed vs successful logins, failure ratio, 401s by endpoint (brute-force detection) |
| Container Restarts | `dashboards/container-restarts.json` | Restarts, OOMKilled, CrashLoopBackOff, top restarting containers |
| CPU & Memory | `dashboards/cpu-memory.json` | Usage vs limits, CPU throttling (a crypto-mining signal) |

The JSON is generated by `build_dashboards.py`, so edit the script and run it again rather
than editing the JSON by hand. To import, go to *Dashboards → New → Import* and pick the
Prometheus data source. You can also load them as ConfigMaps labelled `grafana_dashboard: "1"`
for the kube-prometheus-stack sidecar:

```bash
kubectl -n monitoring create configmap csb-dashboards \
  --from-file=monitoring/grafana/dashboards/ --dry-run=client -o yaml \
  | kubectl label --local -f - grafana_dashboard=1 -o yaml | kubectl apply -f -
```
